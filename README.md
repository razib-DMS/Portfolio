## Run locally

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For a local development server, open the folder in VS Code and use the Live Server extension, or run `python -m http.server 8000` in the folder and visit `http://localhost:8000`.

## Site structure guide

- **Home:** Role headline, concise business-plus-technology introduction, and clear “Explore the case study” and “Let’s connect” calls to action.
- **Portfolio / Projects:** Lead with the EduGrowth master case study and keep Product Management, Digital Marketing, and Data Analytics as distinct sections under one project.
- **Skills:** Group business capabilities separately from technical tools so recruiters can scan both quickly.
- **Certifications:** Show provider, credential name, earned or in-progress status, completion date, and a credential link when available.
- **Contact:** Keep the email, copy-email action, LinkedIn, Facebook, and WhatsApp links easy to find.

The same hierarchy works as a one-page site or as separate Home, Projects, Certifications, and Contact pages in Notion, Wix, or WordPress. Use a restrained corporate palette, consistent spacing, readable type, and one primary CTA per section.

## Portfolio launch checklist

- Confirm the page title and meta description match your professional brand.
- Use a real domain and HTTPS.
- Check the H1 and heading hierarchy.
- Add descriptive alt text if you add images.
- Test all navigation, email, and LinkedIn links.
- Test keyboard navigation, mobile layouts, and contrast.
- Optimize any added images and test page speed.
- Set up Google Search Console after publishing.
- Add a sitemap if you expand the site beyond this one page.
- Add analytics only if appropriate and configure privacy notices where required.
