# Moh. Mominul Islam — Professional Portfolio

A responsive, single-page professional portfolio for Moh. Mominul Islam, presenting his work across SEO, digital marketing, B2B sales development, and global client handling at ZENIVIXON. Built with HTML and CSS, with a small inline script for mobile navigation and the footer year.

## Folder structure

```text
seo-b2b-portfolio/
├── index.html
├── style.css
├── README.md
└── assets/
    └── README.md
```

## Run locally

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For a local development server, open the folder in VS Code and use the Live Server extension, or run `python -m http.server 8000` in the folder and visit `http://localhost:8000`.

## Update before publishing

Replace the sample email (`your.email@example.com`) and LinkedIn URL (`https://www.linkedin.com/in/your-profile/`) in `index.html` with your real contact details. Add approved project case studies, deliverables, and outcomes as available. Keep any client names, performance metrics, and other confidential information out unless you have permission to share them.

Review the skills and tool list carefully. Remove tools and services you have not used or cannot confidently discuss.

## Project honesty

The three project cards currently describe practice concepts, not verified client engagements. Replace them with completed work only when you can accurately describe your role and share supporting deliverables. Do not add client logos, testimonials, traffic gains, revenue numbers, or lead counts unless they are real and permissioned.

## SEO launch checklist

- Confirm the page title and meta description match your professional brand.
- Use a real domain and HTTPS.
- Check the H1 and heading hierarchy.
- Add descriptive alt text if you add images.
- Test all navigation, email, and LinkedIn links.
- Test keyboard navigation, mobile layouts, and contrast.
- Optimize any added images and test page speed.
- Set up Google Search Console after publishing.
- Add a sitemap if you expand the site beyond this one page.
- Add analytics only if appropriate and configure privacy notices where required.

## Deploy options

This static site can be hosted with GitHub Pages, Netlify, Cloudflare Pages, or any static web host. Follow the host's current instructions for connecting your repository or uploading the files.

## Notes

- Google Fonts are loaded from an external service; the page still has sans-serif fallback fonts if they are unavailable.
- No form backend is included. The contact button uses `mailto:` and the LinkedIn button opens a profile.
- The website describes your role and experience at a high level; add specific dates, tools, case studies, and results only when confirmed and approved for sharing.
